# GECPL — AI & ML Experiments

Standardized repository for Semester 7 AI and ML practical experiments.

## Repository Structure

```
GECPL/
├── README.md
├── .gitignore
├── AI/
│   ├── EXPERIMENT1.py
│   ├── EXPERIMENT2.py
│   ├── ...
│   └── EXPERIMENT13.py / .pl
└── ML/
    ├── EXPERIMENT1.py
    ├── EXPERIMENT2.py
    ├── ...
    └── EXPERIMENT12.py
```

## Branching Strategy

- `main` — Production-ready, fully reviewed code
- `dev` — Integration branch for all experiments
- `newfeature/experiment-ai-X` — Individual AI experiment branches
- `newfeature/experiment-ml-X` — Individual ML experiment branches

## Workflow

```
newfeature/experiment-X → PR → dev → PR → main
```
